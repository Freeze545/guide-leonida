# Guide Léonida

Site de fans **non officiel**, non affilié à Rockstar Games. Guides *Grand Theft Auto VI* en français, mobile d’abord, uniquement avec des faits vérifiés.

- Plan de lancement et de monétisation : [PLAN.md](PLAN.md)
- Stack : HTML / CSS / JS statique, sans cadre lourd
- Police d’affichage : [Syne](https://github.com/googlefonts/syne) (SIL Open Font License)

## Déploiement

Site statique. Sur Render : `runtime: static`, `buildCommand: true`, `staticPublishPath: .` (voir `render.yaml`).

## Contenu

Les pages de guides qui exigent des données en jeu (carte détaillée, collectibles, codes, listes d’armes ou de véhicules) restent en « Bientôt — mis à jour dès la sortie ». Ne pas inventer de faits de jeu.
